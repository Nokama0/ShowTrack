# ShowTrack Android Port — Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ShowTrack builds, installs, and runs well on the user's Samsung phone as a signed APK — standalone (own DB, TMDB onboarding), with a phone-fit UI — per Phase 1 of `docs/superpowers/specs/2026-07-09-android-port-design.md`.

**Architecture:** Tauri 2's Android target in the same repo: `tauri android init` generates the Gradle project under `src-tauri/gen/android`; the existing Rust core and Svelte UI compile into the APK. Portability fixes (rustls, poster origin, zoom hide) + a media-query mobile UI pass (bottom tab bar, touch targets, bottom-sheet modal) + Android theme colors + release signing.

**Tech Stack:** existing app stack + rustup Android targets, Android SDK/NDK (via installed Android Studio), Gradle (generated), adb.

## Global Constraints

- Branch `feature/android` off master. Repo `G:\Projects\showtrack`.
- **THE ACCEPTANCE BAR IS MOBILE LOOK/FEEL** — the user reserves the option to go native if this feels bad. Screenshot early (adb) and treat visual quality as a gate, not an afterthought.
- Desktop rendering and behavior unchanged: all mobile UI lives behind `@media (max-width: 760px)` or the `isAndroid` platform check. Desktop gates keep passing at every task: `cargo test` (36 passed, 2 ignored), `pnpm check` 0/0, `pnpm build` clean.
- Design tokens/copy rules unchanged (gold #ffcf6e system, no em dashes, animations never gated on reduced-motion).
- Secrets: `showtrack-release.keystore` and `keystore.properties` are generated locally and MUST be gitignored; verify `git status` shows neither before any commit.
- Environment for every Android build command (set per session; also documented in README by Task 6):
  `$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"`,
  `$env:ANDROID_HOME = "$env:LOCALAPPDATA\Android\Sdk"`,
  `$env:NDK_HOME = <newest dir under $env:ANDROID_HOME\ndk>` (Task 1 discovers/install it).
- The phone (Samsung, ADB known-working on this machine) is only needed in Task 6; Tasks 1–5 verify via debug APK builds (and optionally the Android Studio emulator).

Verify both files are ignored: `git status` must not list them.

- [ ] **Step 2: Gradle signing config**

In `src-tauri/gen/android/app/build.gradle.kts`: at the top add
```kotlin
import java.io.FileInputStream
import java.util.Properties
```
inside `android { ... }` add
```kotlin
    signingConfigs {
        create("release") {
            val props = Properties()
            val f = rootProject.file("keystore.properties")
            if (f.exists()) {
                props.load(FileInputStream(f))
                storeFile = file(props["storeFile"] as String)
                storePassword = props["storePassword"] as String
                keyAlias = props["keyAlias"] as String
                keyPassword = props["keyPassword"] as String
            }
        }
    }
```
and in `buildTypes { release { ... } }` add `signingConfig = signingConfigs.getByName("release")`.
