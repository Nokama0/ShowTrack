# UI Zoom Control Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A persisted whole-UI zoom setting (80–150%, default 100) adjustable from the Settings screen, per the approved spec `docs/superpowers/specs/2026-07-03-ui-zoom-design.md`.

**Architecture:** Native webview zoom (`getCurrentWebview().setZoom`) applied from a `$effect` in the root layout that reads `session.zoom`; the value is loaded from the existing `settings` table (`ui_zoom`) in `loadSession()` and persisted with the existing `settings_set` command. Frontend-only.

**Tech Stack:** Svelte 5 runes, `@tauri-apps/api/webview`, existing settings commands.

## Global Constraints

- Value is a percent integer, clamp range **80–150**, step **10**, default **100**; stored as string under key `ui_zoom`.
- No Rust changes. Gates: `pnpm check` 0 errors 0 warnings, `pnpm build` clean.
- Capability `core:webview:allow-set-webview-zoom` must be added to `src-tauri/capabilities/default.json`.
- Rebuild the runnable exe afterwards with `pnpm tauri build --no-bundle` (kill any running `showtrack` process first).

- [ ] **Step 3: Apply zoom in the layout**

`src/routes/+layout.svelte` — add to the imports:
```ts
  import { getCurrentWebview } from "@tauri-apps/api/webview";
```
and after the `onMount(...)` block:
```ts
  $effect(() => {
    // cosmetic: ignore failures, app stays at current zoom
    getCurrentWebview().setZoom(session.zoom / 100).catch(() => {});
  });
```

- [ ] **Step 4: Settings stepper**

`src/routes/settings/+page.svelte` — script already imports `api` and `session`; add:
```ts
  function bumpZoom(delta: number) {
    const next = Math.min(150, Math.max(80, session.zoom + delta));
    if (next === session.zoom) return;
    session.zoom = next; // layout $effect applies it live
    api.settingsSet("ui_zoom", String(next)).catch((e) => (session.banner = String(e)));
  }
```
Markup — new panel between the "TMDB API key" and "Import from TV Time" sections:
```svelte
<div class="panel section">
  <h2>UI scale</h2>
  <div class="row" style="align-items:center">
    <button onclick={() => bumpZoom(-10)} disabled={session.zoom <= 80} aria-label="Smaller">▼</button>
    <span class="zoomval">{session.zoom}%</span>
    <button onclick={() => bumpZoom(10)} disabled={session.zoom >= 150} aria-label="Larger">▲</button>
  </div>
</div>
```
Style (append to the page's `<style>`):
